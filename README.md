# Employee Data Visualization

A Python-based data visualization project that analyzes employee information from a CSV file and presents the results using graphs.

## Features

- Reads employee data from a CSV file.
- Processes employee information using Python.
- Generates graphs for easier data analysis.
- Uses popular Python data analysis and visualization libraries.

## Project Structure

```text
graph/
├── employee_data.csv
├── graph.py
├── requirements.txt
└── README.md
```

## Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn

## Installation

1. Clone the repository:

```bash
git clone [https://github.com/roshnirawat909/graph.git](https://github.com/roshnirawat909/graph.git)
```

2. Open the project directory:

```bash
cd graph
```

3. Create a virtual environment:

```bash
python -m venv venv
```

4. Activate the virtual environment.

On Windows:

```bash
venv\Scripts\activate
```

On macOS/Linux:

```bash
source venv/bin/activate
```

5. Install the required dependencies:

```bash
pip install -r requirements.txt
```

## Usage

Run the Python script:

```bash
python graph.py
```

Make sure that `employee_data.csv` is present in the same directory as `graph.py`.

## Dataset

The project uses `employee_data.csv` as its input dataset. The dataset contains employee-related information used to create visual representations and perform basic analysis.
